Publications

Quipu: A Governed Bitemporal Knowledge Graph Store
arXiv:2608.16813 · cs.AI, cross-listed cs.DB · 2026 · 10.5281/zenodo.21878610

Knowledge-graph stores still carry defaults set when humans curated them: accept writes now and clean later, one time axis or none, every writer equally trusted, governance left to dashboards. Quipu inverts all four. No fact enters except through a gate that evaluates the pending post-state; data, trust labels, verdicts and the validation rules themselves are bitemporal; and the governance specification and its signed verdicts are facts in the store they govern, which makes the audit a query. Archived artifact: 10.5281/zenodo.21878428.

Projects

bobbin, quipu and yupana are one system rather than three side projects: retrieval, governed knowledge and live code structure for agents. The rest are the pieces around it, and caboodle is what binds them into one install.

quipuRust

AI-native knowledge graph with strict ontology enforcement over RDF, SPARQL and SHACL. Governance as a write-path gate rather than a dashboard. 28 Model Context Protocol tools.

yupanaRust

Live per-tenant code-structure engine. Answers what calls this, what flows into this, and what a change will break, by fusing call graphs, dataflow, co-change history and embeddings. Shared baseline plus per-developer overlays, so many humans and agents edit concurrently without corrupting each other's view.

bobbinRust

Local-first code context engine for AI agents: hybrid search, git co-change coupling analysis, and MCP integration.

camayocPython

The knot-keeper. Bootstrap ontology, knowledge ingress and portable knowledge packs for the quipu stack, so a store starts governed instead of being governed later.

shuttlePython

The workflow engine of the stack. Every transition signed, every window frozen, so what an agent did and what it was allowed to do stay the same record.

caboodleRust

The whole kit, and what binds the stack together. One wizard that installs quipu, yupana, bobbin and the pieces around them, proves the install actually works, and then watches it run.

creelJavaScript

Parallel agent bursts that run entirely in the browser. Tabs as workers, WASM as the sandbox, the knowledge graph in the page. No server-side harness and no secrets held.

shantytownPython

A small harness for running a crew of coding agents. Create a work item, tell an agent to go get it; dispatch, escalation and recovery are the whole surface.

skeinPython

Portable agentic skills for coding agents. Shell and HTTP only, no framework and no runtime: copy a directory in and it works.

pixelsrcRust

A GenAI-native pixel-art format and compiler. Semantic and human-readable, optimized for LLM generation, so no spatial reasoning is required.
